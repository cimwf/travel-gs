# 周末约行页面清单

> 基线日期：2026-08-19。页面注册顺序以 `miniprogram/app.json` 为准。

## 系统 Tab

| 页面 | 路径 | 主要功能 |
| --- | --- | --- |
| 社区 | `pages/community/community` | 全部/关注、地区筛选、10 条分页、点赞评论、发布入口 |
| 行程 | `pages/trip-list/trip-list` | 行程列表、筛选、10 条分页、发布入口 |
| 我的 | `pages/profile/profile` | 个人资料、统计、作品、互动、行程、消息和设置入口 |

登录成功默认回到社区首页。

## 社区与互动

| 页面 | 路径 | 主要功能 |
| --- | --- | --- |
| 社区详情 | `pages/community-detail/community-detail` | 动态详情、点赞列表、评论/回复、分享、删除、举报 |
| 发布动态 | `pages/community-publish/community-publish` | 文字、多图、主动选择位置、COS 上传 |
| 我的作品 | `pages/community-mine/community-mine` | 已发布、待复核、审核不通过及未删除作品 |
| 我的互动 | `pages/community-interactions/community-interactions` | 赞过和评论过的内容 |
| 获赞列表 | `pages/community-likes/community-likes` | 动态点赞用户列表 |
| 举报 | `pages/report/report` | 理由、说明、图片和目标内容提交 |

## 行程

| 页面 | 路径 | 主要功能 |
| --- | --- | --- |

| 景点详情 | `pages/place-detail/place-detail` | 景点信息及相关行程入口 |

## 用户、消息和设置

| 页面 | 路径 | 主要功能 |
| --- | --- | --- |
| 登录/完善资料 | `pages/auth/auth` | 微信头像昵称、登录和资料创建 |

## 未注册的历史页面

`pages/index`、`pages/messages`、`pages/chat`、`pages/comments`、`pages/search` 和
`pages/settings` 仍保留部分文件，但当前没有注册到 `app.json`，不属于正式访问链路。
修改这些页面不会自动影响线上功能，重新启用前需要先确认业务和数据接口。
