# 云开发配置指南

## 1. 开通云开发

### 步骤

1. 打开微信开发者工具
2. 点击工具栏「云开发」按钮
3. 首次开通会创建环境，记录环境ID（如：`cloud1-xxx`）
4. 选择「基础版」（免费额度）

---

## 2. 配置环境ID

修改 `miniprogram/app.js`：

```javascript
wx.cloud.init({
  env: 'cloud1-xxx',  // 替换为你的环境ID
  traceUser: true
});
```

修改 `project.config.json`：

```json
{
  "cloudfunctionRoot": "cloudfunctions/",
  "cloudbaseRoot": "cloudbaserc.json",
  "miniprogramRoot": "miniprogram/"
}
```

---

## 3. 创建数据库集合

在云开发控制台 → 数据库，创建以下集合：

| 集合名 | 说明 |
|--------|------|
| users | 用户表 |
| places | 地点表 |
| trips | 行程表 |
| applies | 申请表 |
| wants | 想去表 |
| messages | 消息表 |
| comments | 评论表 |
| notifications | 通知表 |

---

## 4. 导入初始数据

### 方式一：控制台手动添加

1. 打开云开发控制台 → 数据库 → places 集合
2. 点击「添加记录」
3. 复制 `database/init-places.js` 中的数据逐条添加

### 方式二：云函数批量导入

创建临时云函数：

```javascript
// cloudfunctions/init-data/index.js
const cloud = require('wx-server-sdk');
cloud.init({ env: cloud.DYNAMIC_CURRENT_ENV });
const db = cloud.database();

const initialPlaces = [/* 从 database/init-places.js 复制 */];

exports.main = async (event, context) => {
  for (const place of initialPlaces) {
    await db.collection('places').add({ data: place });
  }
  return { success: true, count: initialPlaces.length };
};
```

上传并调用该云函数即可批量导入。

---

## 5. 上传云函数

### 方式一：右键上传

1. 在微信开发者工具中
2. 展开 `cloudfunctions` 文件夹
3. 右键点击 `api` 文件夹
4. 选择「上传并部署：云端安装依赖」

### 方式二：命令行上传

```bash
# 安装云函数依赖
cd cloudfunctions/api
npm install

# 上传（需在开发者工具中）
```

---

## 6. 开启云开发模式

修改 `miniprogram/pages/index/index.js`：

```javascript
data: {
  useCloud: true  // 改为 true
}
```

## 7. 数据库索引配置

在云开发控制台 → 数据库 → 索引管理，添加以下索引：

### users 集合
```json
{"openid": 1}  // 唯一索引
```

### trips 集合
```json
{"placeId": 1}
{"creatorId": 1}
{"date": -1}
{"status": 1}
```

### applies 集合
```json
{"tripId": 1, "status": 1}
{"userId": 1}
{"creatorId": 1}
```

### messages 集合
```json
{"conversationId": 1, "createdAt": -1}
{"toUserId": 1, "read": 1}
```

## 常见问题

### Q: 云函数调用失败

检查：
1. 环境ID是否正确配置
2. 云函数是否已上传
3. 是否有云函数调用权限

### Q: 数据库操作失败

检查：
1. 集合是否已创建
2. 数据库权限配置（开发阶段可设置为「所有用户可读写」）

### Q: 免费额度不够用

建议：
1. 优化查询，减少读操作
2. 使用本地缓存
3. 升级付费套餐

## 新 prod 环境迁移清单

> 每次建立新的生产环境时，按以下顺序逐项确认。

### 一、云函数 `api` 配置

#### 1. 超时时间

云开发控制台 → 云函数 → `api` → 函数配置 → **超时时间设为 60 秒**

> 默认 3 秒不够，下载 + 上传 AI 生成图片到云存储需要 10～30 秒。

#### 2. 必填环境变量

| 变量名 | 说明 | 是否必填 |
|--------|------|----------|
| `AI_IMAGE_SERVICE_URL` | 外部 AI 生图服务地址 | ✅ 必填 |
| `AI_IMAGE_SERVICE_SECRET` | 外部 AI 生图服务密钥 | ✅ 必填 |
| `TOKEN_SECRET` | JWT 签名密钥，生产环境必须改掉默认值 | ✅ 必填 |

#### 3. 可选环境变量（有默认值）

| 变量名 | 默认值 | 说明 |
|--------|--------|------|
| `OPENAI_API_KEY` | 无 | 直连 OpenAI 时填写，走外部服务可不填 |
| `OPENAI_IMAGE_MODEL` | `gpt-image-2` | 图像生成模型 |
| `OPENAI_RESPONSES_MODEL` | `gpt-4.1-mini` | 对话模型 |
| `AI_IMAGE_TASK_EXPIRE_MS` | 内置默认值 | 任务超时毫秒数 |
| `AI_IMAGE_DOWNLOAD_MAX_BYTES` | 内置默认值 | 单张图片最大下载字节数 |
| `AI_IMAGE_DOWNLOAD_ALLOWLIST` | 内置白名单 | 额外允许的图片下载域名，逗号分隔 |
| `AI_IMAGE_DOWNLOAD_REQUIRE_ALLOWLIST` | `false` | 是否强制只允许白名单域名 |
| `AI_IMAGE_ALLOW_HTTP_DOWNLOADS` | `false` | 是否允许 HTTP（非 HTTPS）下载 |
| `AI_IMAGE_STORAGE_BUCKET` / `COS_BUCKET` | 当前云环境 | 自定义云存储 Bucket |
| `TCB_ENV` / `SCF_NAMESPACE` | 运行时自动注入 | 云环境 ID，一般不用手动配置 |

### 二、云托管环境变量

云开发控制台 → 云托管 → 对应服务 → 环境变量，逐一核对是否与 prod 配置一致。

重点检查项：
- 服务端接口鉴权相关的密钥是否已替换为生产值
- 数据库连接字符串、Bucket 名称是否指向 prod 环境

### 三、数据库集合

确认以下集合已在 prod 环境创建（参见本文第 3 节），并追加 AI 生图相关集合：

| 集合名 | 说明 |
|--------|------|
| `ai_image_generations` | AI 生图任务记录 |
| `ai_image_quotas` | 用户生图配额 |
| `ai_image_channels` | 生图渠道配置 |
| `ai_image_templates` | 生图模板 |

## 权限配置

开发阶段建议将数据库权限设置为：

- **读权限**：所有用户可读
- **写权限**：仅创建者可写

生产环境建议使用安全规则：

```json
{
  "read": "auth.openid == doc._openid",
  "write": "auth.openid == doc._openid"
}
```
