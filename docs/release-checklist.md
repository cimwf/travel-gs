# 上线检查清单

> 每次提交体验版或微信审核前复制一份执行记录。不要因为本地测试通过就跳过真机、
> 云函数、数据权限和回调检查。

## P0：必须完成

### 代码与配置

- [ ] 当前分支、版本号和项目备注正确，工作区没有误提交文件。
- [ ] `app.json` 页面、Tab 顺序和隐私权限描述符合当前产品。
- [ ] `miniprogram/utils/env.js` 为 `develop/dev`、`trial/test`、`release/prod`。
- [ ] `project.config.json` 打开 URL 校验并完成合法域名真机验证。
- [ ] 上传包中没有 SecretId、SecretKey、管理员密码、测试手机号或敏感日志。

### 云函数与数据库

- [ ] `login`、`api`、`community-media-check-result` 已部署到正确云环境。
- [ ] `api` 的 COS、TOKEN 环境变量完整且使用生产密钥。
- [ ] 所有集合的小程序端权限为“所有用户不可读写”。
- [ ] 社区、行程、评论、关注、通知、审核和后台分页在非空数据下无缺失索引。
- [ ] 后台景点、反馈、用户上传、图片资源和审核页面均通过云函数读取。

### 内容安全

- [ ] `msgSecCheck` 和 `mediaCheckAsync` 权限生效。
- [ ] `wxa_media_check` 消息推送规则已启用并指向正确回调云函数。
- [ ] 正常图、`review`、`risky` 三类状态在社区和旅行记录后台显示正确。
- [ ] 社区作品和旅行记录风险建议保持公开，只有人工拒绝才隐藏。
- [ ] 社区/行程图片评论的 `risky` 回调能够隐藏对应评论并正确回减数量。
- [ ] 后台可以复核社区、行程、旅行记录并查看举报目标。

### 核心真机流程

- [ ] 新用户：同意隐私协议、选择微信头像昵称、完成登录且不出现数据库权限错误。
- [ ] 老用户：登录、编辑头像/昵称/年龄/地区、保存后局部刷新。
- [ ] 社区：分页、全部/关注、地区筛选、纯文字、1 图、多图、位置、删除和分享。
- [ ] 社区评论：文字、最多 3 图、回复回复、长按删除、地区展示和通知跳转。
- [ ] 行程：发布、目的地定位、封面、详情展示、编辑、取消、分享和环境隔离。
- [ ] 申请：可选留言、发起人查看完整留言、同意/拒绝、取消和成员状态。
- [ ] 旅行记录：未出发限制、发布、位置、多图、审核、删除和局部下拉刷新。
- [ ] 行程评论：文字、图片、回复和删除。
- [ ] 消息：未读横幅、消息中心分类、全部已读、通知详情不无限 loading。
- [ ] 举报和反馈可以成功提交，后台能够查看。

### COS

- [ ] 头像、社区作品、社区评论、行程封面、旅行记录和行程评论均写入正确目录。
- [ ] request/uploadFile/downloadFile 合法域名及 COS CORS 正确。
- [ ] 上传凭证只允许本次生成的对象 Key，永久密钥未下发前端。
- [ ] 删除作品、日志和替换封面后检查 COS；失败任务进入清理集合。

### 环境隔离

- [ ] 开发版只展示 `dev`，体验版只展示 `test`，正式版只展示 `prod`。
- [ ] 没有 `dataEnv` 的旧数据不会进入正式版。
- [ ] 个人主页行程与首页行程使用相同环境规则。
- [ ] 官方动态先进入 `dev`，后台发布后变成 `prod` 且发布时间更新为当前时间。

## P1：建议完成

- [ ] iOS 和 Android 各完成一次核心流程。
- [ ] 弱网、上传中断、重复点击、空列表、最后一条删除和分页末尾均验证。
- [ ] 云函数错误、图片审核超时和 COS 清理积压设置监控或人工巡检。
- [ ] 核对 COS 存储、流量和云开发调用预算。
- [ ] 备份关键集合，并明确软删除和举报数据保留周期。
- [ ] 清理开发/体验环境无用图片、审核 trace、旧消息和测试账号。

## 自动测试

```bash
npm test
npm run test:community
npm run test:trip-comment
npm run test:trip-log
npm run test:trip-log-review
npm run test:trip-media
npm run test:trip-review
npm run test:data-env
npm run test:notification
npm run test:admin-data
```

测试失败必须先判断是代码回归还是旧 mock 过时；不能直接忽略。自动测试不覆盖真实微信
隐私弹窗、COS CORS、合法域名、云数据库索引和异步审核消息推送。

## 提交信息建议

- **更新类型**：新增明显能力选“特性更新”；只修复问题选“修订补丁”；第一版或产品
  定位大改才使用“版本升级”。
- **项目备注**：用用户可验证的语言写本次改动，不写内部实现细节或“第一个大版本”等
  无法帮助审核员定位功能的描述。
- 审核需要录屏时，覆盖登录、首页、发布、内容展示、举报入口和隐私授权场景。
