# 行程评论上线说明

## 功能

- 行程详情固定展示「行程 / 旅途记录 / 评论」三个 Tab，默认进入行程。
- 评论支持纯文字主评论、回复主评论、回复回复。
- 评论与回复发布前调用微信 `msgSecCheck` V2，只有 `pass` 才会入库。
- 评论作者可删除自己的内容；行程发起人可删除该行程下的任意评论或回复。
- 评论和回复会写入互动通知，点击通知进入对应行程详情。
- 未出发时仍能打开旅途记录 Tab，保留原有空状态；点击发布日志会提示「出发后才能发布日志」。

## 上线前操作

1. 在云开发数据库创建 `trip_comments` 和 `trip_comment_replies` 集合。
2. 创建以下非唯一复合索引，字段顺序不要调换：
   - `trip_comments`: `tripId` 升序 + `status` 升序 + `createdAt` 降序 + `_id` 降序。
   - `trip_comment_replies`: `tripId` 升序 + `rootCommentId` 升序 + `status` 升序 + `createdAt` 升序 + `_id` 升序。
3. 重新上传并部署 `api` 云函数，选择「云端安装依赖」。
4. 确认小程序后台的内容安全能力和 `msgSecCheck` 调用权限可用。

集合权限建议设为「仅云函数可读写」，前端所有评论操作都通过 `api` 云函数进行。
