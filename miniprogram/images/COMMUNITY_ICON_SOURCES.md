# Community icon sources

The community Tab and community-page interface icons are rasterized from
Bootstrap Icons 1.13.1:

- `people-fill`
- `camera`
- `geo-alt-fill`
- `globe2`
- `three-dots`
- `plus-lg`
- `x-lg`
- `arrow-left`

Source: https://github.com/twbs/icons/tree/v1.13.1

The upstream MIT license is stored in `BOOTSTRAP_ICONS_LICENSE`.
