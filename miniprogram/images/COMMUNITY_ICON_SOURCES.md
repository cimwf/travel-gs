# Community icon sources

The community Tab and community-page interface icons are rasterized from
Bootstrap Icons 1.13.1:

- `people-fill`
- `camera`
- `geo-alt-fill`
- `globe2`
- `three-dots`
- `plus-lg`
- `x-lg`
- `arrow-left`

Source: https://github.com/twbs/icons/tree/v1.13.1

The upstream MIT license is stored in `BOOTSTRAP_ICONS_LICENSE`.

The community comment icon uses Heroicons 2.2.0:

- `chat-bubble-oval-left-ellipsis`

Source: https://github.com/tailwindlabs/heroicons/tree/v2.2.0

The upstream MIT license is stored in `HEROICONS_LICENSE`.

The community like icons use Tabler Icons 3.34.1:

- `heart` (outline and filled)

Source: https://github.com/tabler/tabler-icons/tree/v3.34.1

The upstream MIT license is stored in `TABLER_ICONS_LICENSE`.
